Waziup is pleased to announce the release of WaziGate V3.1, the latest version of its IoT gateway, featuring several enhancements designed to improve connectivity, performance and reliability across IoT deployments.

The new release introduces key improvements, including:
- VPN Support: Enables more secure connectivity for IoT deployments.
- UPS Module Support: Provides greater power resilience.
- Reduced Network Traffic: Improves communication efficiency and reduces unnecessary network traffic.
- Improved Dashboard Sessions: Enhances session handling for a smoother management experience.
- Enhanced LoRa Downlink Handling: Improves payload handling and queue management for more reliable communication.
These updates strengthen WaziGate's capabilities as a gateway for managing IoT networks, helping make deployments more secure, efficient and dependable.

Waziup continues to improve its IoT infrastructure to support developers, organisations and innovators building connected solutions across different application areas.
